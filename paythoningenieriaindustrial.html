2Fundamentos de Python

Todo programa manipula información. Antes de resolver problemas complejos, es necesario comprender cómo se representa y se almacena esa información dentro de un programa.

2.1 Variables y tipos de datos

Una variable es un nombre que guarda un valor en la memoria para poder utilizarlo después. Se crea con el signo igual, donde a la izquierda se coloca el nombre y a la derecha el valor.

Celda de código — variables
# Creación de variables de distintos tipos
producto = "Tornillo hexagonal"   # texto (str)
cantidad = 150                    # número entero (int)
precio_unitario = 2.75           # número decimal (float)
disponible = True                # valor lógico (bool)

print(producto)
print("Cantidad en almacén:", cantidad)

La función type() permite conocer el tipo de dato de una variable, lo cual es útil para verificar que la información se está almacenando correctamente.

Celda de código — tipos
print(type(cantidad))          # <class 'int'>
print(type(precio_unitario))   # <class 'float'>
print(type(producto))          # <class 'str'>
Reglas para nombrar variables. Deben iniciar con letra, no contener espacios (se usa el guion bajo), y conviene que su nombre describa lo que almacenan. Un nombre claro como precio_unitario es preferible a uno ambiguo como p.

2.2 Operadores y entrada de datos

Los operadores permiten realizar cálculos y comparaciones. La función input() permite que el programa reciba datos escritos por el usuario.

OperadorFunciónEjemploResultado
+  -Suma y resta10 + 515
*  /Multiplicación y división10 / 42.5
//División entera10 // 42
%Residuo (módulo)10 % 42
**Potencia2 ** 38

El valor que devuelve input() siempre es texto. Para operar con números, se convierte con int() (entero) o float() (decimal).

Celda de código — entrada y cálculo
# Cálculo del valor total de un lote de material
nombre = input("Nombre del material: ")
unidades = int(input("Número de unidades: "))
costo = float(input("Costo por unidad: "))

total = unidades * costo
print("El valor total de", nombre, "es:", total)

3Estructuras de control

Las estructuras de control permiten que el programa tome decisiones y repita acciones. Sin ellas, un programa ejecutaría siempre las mismas líneas en el mismo orden.

3.1 Condicionales: if, elif, else

Una condición evalúa si una afirmación es verdadera o falsa y ejecuta un bloque de código según el resultado. En Python, el bloque que depende de la condición se distingue por la sangría (indentación).

OperadorSignificado
==Igual a
!=Distinto de
>   <Mayor que, menor que
>=   <=Mayor o igual, menor o igual
Celda de código — condicional
# Control del nivel de existencias en almacén
existencias = 8
minimo = 10

if existencias == 0:
    print("Sin existencias. Detener línea de producción.")
elif existencias < minimo:
    print("Existencias por debajo del mínimo. Generar pedido.")
else:
    print("Nivel de inventario adecuado.")
Atención a la sangría. Python exige que las líneas dentro de un if tengan una sangría uniforme (habitualmente cuatro espacios). Una sangría incorrecta produce el error IndentationError.

3.2 Ciclos: for y while

Un ciclo repite un bloque de código. El ciclo for recorre una secuencia de elementos; el ciclo while se repite mientras una condición sea verdadera.

Celda de código — ciclo for
# Recorrer los turnos de producción de una jornada
for turno in range(1, 4):      # genera 1, 2, 3
    print("Registrando producción del turno", turno)
Celda de código — ciclo while
# Descontar unidades hasta agotar un lote
unidades = 5
while unidades > 0:
    print("Unidades disponibles:", unidades)
    unidades = unidades - 1
print("Lote agotado.")

4Estructuras de datos

Para gestionar un inventario no basta con variables individuales: se requiere almacenar conjuntos de datos organizados. Python ofrece las listas y los diccionarios para este propósito.

4.1 Listas y diccionarios

Una lista es una colección ordenada de elementos. Cada elemento tiene una posición o índice que inicia en cero.

Celda de código — listas
# Lista de materiales del almacén
materiales = ["Tornillos", "Tuercas", "Arandelas", "Remaches"]

print(materiales[0])          # primer elemento: Tornillos
print(len(materiales))       # número de elementos: 4

materiales.append("Clavos")   # agrega un elemento al final

for material in materiales:  # recorre toda la lista
    print("Material en almacén:", material)

Un diccionario almacena pares de clave y valor. Es ideal para describir un objeto con varios atributos, como un producto del inventario.

Celda de código — diccionario
# Un producto descrito con un diccionario
producto = {
    "nombre": "Tornillo hexagonal",
    "cantidad": 150,
    "precio": 2.75
}

print(producto["nombre"])     # accede al valor por su clave
producto["cantidad"] = 130    # modifica un valor existente
print(producto)
Combinación poderosa. Una lista de diccionarios permite representar un inventario completo: cada diccionario es un producto y la lista los agrupa a todos. Esta estructura será la base del proyecto final.

5Funciones

Una función es un bloque de código con nombre que realiza una tarea específica y puede reutilizarse. Las funciones permiten organizar el programa, evitar la repetición y facilitar su mantenimiento.

Se definen con la palabra def, pueden recibir datos de entrada llamados parámetros y devolver un resultado con return.

Celda de código — definición de función
# Función que calcula el valor total de un producto en inventario
def valor_inventario(cantidad, precio):
    total = cantidad * precio
    return total

# Uso de la función con distintos valores
valor1 = valor_inventario(150, 2.75)
valor2 = valor_inventario(80, 5.20)

print("Valor del producto 1:", valor1)
print("Valor del producto 2:", valor2)
Ventaja. Una vez definida, la función valor_inventario puede llamarse cuantas veces sea necesario con distintos datos, sin volver a escribir la fórmula.

6Datos externos: hojas de cálculo con Pandas

Los programas cobran verdadera utilidad cuando trabajan con datos reales almacenados en archivos. Pandas es la biblioteca estándar de Python para leer, transformar y escribir datos tabulares, como los de una hoja de cálculo. Su estructura principal es el DataFrame, que representa una tabla con filas y columnas.

6.1 Lectura y escritura de archivos

Pandas ya viene disponible en Google Colab. Para usarlo, primero se importa. La convención es asignarle el nombre corto pd.

Celda de código — crear y guardar una tabla
import pandas as pd

# Se construye una tabla a partir de un diccionario
datos = {
    "Producto": ["Tornillos", "Tuercas", "Arandelas"],
    "Cantidad": [150, 200, 90],
    "Precio": [2.75, 1.50, 0.80]
}

inventario = pd.DataFrame(datos)   # crea el DataFrame (la tabla)
print(inventario)

# Guardar la tabla como archivo de hoja de cálculo
inventario.to_excel("inventario.xlsx", index=False)
print("Archivo guardado correctamente.")
Ubicación del archivo. El archivo inventario.xlsx se guarda en el panel de archivos de Colab (icono de carpeta a la izquierda). Desde ahí puede descargarse al equipo. También puede subirse un archivo existente para leerlo.

Para leer un archivo de hoja de cálculo ya existente se utiliza read_excel:

Celda de código — leer una hoja de cálculo
# Leer el archivo guardado previamente
inventario = pd.read_excel("inventario.xlsx")

print(inventario.head())          # muestra las primeras filas
print("Columnas:", list(inventario.columns))

Las operaciones más frecuentes sobre un DataFrame son consultar, filtrar y actualizar valores:

Celda de código — consultar y actualizar
# Calcular una nueva columna con el valor total por producto
inventario["Valor"] = inventario["Cantidad"] * inventario["Precio"]

# Filtrar productos con menos de 100 unidades
bajo_stock = inventario[inventario["Cantidad"] < 100]
print(bajo_stock)

# Guardar los cambios de nuevo en el archivo
inventario.to_excel("inventario.xlsx", index=False)

7Ejercicio integral guiado

Este ejercicio reúne los conceptos estudiados en un solo programa: variables, estructuras de datos, condicionales, ciclos, funciones y manejo de hojas de cálculo. Se construye paso a paso. Reproduzca cada bloque en una celda distinta de Colab y verifique su resultado antes de continuar.

Problema planteado

Un almacén requiere un programa que registre productos, calcule el valor total del inventario, identifique los productos que necesitan reabastecimiento y guarde toda la información en una hoja de cálculo.

Paso 1. Preparar el entorno y la estructura de datos

Se importa Pandas y se define el inventario como una lista de diccionarios, donde cada diccionario es un producto.

Celda 1 — estructura inicial
import pandas as pd

inventario = [
    {"nombre": "Tornillos",  "cantidad": 150, "precio": 2.75, "minimo": 50},
    {"nombre": "Tuercas",    "cantidad": 40,  "precio": 1.50, "minimo": 60},
    {"nombre": "Arandelas",  "cantidad": 90,  "precio": 0.80, "minimo": 30}
]
print("Inventario cargado con", len(inventario), "productos.")

Paso 2. Función para calcular el valor de cada producto

Se define una función que recibe un producto y devuelve el valor de sus existencias.

Celda 2 — función de valor
def calcular_valor(producto):
    return producto["cantidad"] * producto["precio"]

# Prueba con el primer producto de la lista
print("Valor del primer producto:", calcular_valor(inventario[0]))

Paso 3. Recorrer el inventario y evaluar cada producto

Con un ciclo for se recorre la lista; con un condicional se determina si cada producto requiere reabastecimiento.

Celda 3 — recorrido y evaluación
valor_total = 0

for producto in inventario:
    valor = calcular_valor(producto)
    valor_total = valor_total + valor

    if producto["cantidad"] < producto["minimo"]:
        estado = "REABASTECER"
    else:
        estado = "Suficiente"

    print(producto["nombre"], "- Valor:", valor, "- Estado:", estado)

print("Valor total del inventario:", valor_total)

Paso 4. Exportar el inventario a una hoja de cálculo

Se convierte la lista de diccionarios en un DataFrame, se agrega la columna de valor y se guarda como archivo de hoja de cálculo.

Celda 4 — exportación
tabla = pd.DataFrame(inventario)
tabla["valor"] = tabla["cantidad"] * tabla["precio"]

tabla.to_excel("inventario_general.xlsx", index=False)
print("Inventario exportado a inventario_general.xlsx")
print(tabla)

8Proyecto final: Sistema de Gestión de Inventarios

En este proyecto el estudiante construye, desde cero y paso a paso, un sistema funcional que permite registrar productos, consultarlos, actualizar sus existencias y conservar toda la información en un archivo de hoja de cálculo actualizable. El sistema integra la totalidad de los conocimientos de la guía y reproduce una necesidad real de la ingeniería industrial: el control de inventarios.

Requisitos funcionales del sistema

  • Cargar el inventario desde un archivo de hoja de cálculo, o crearlo si no existe.
  • Mostrar el inventario completo en pantalla.
  • Registrar un nuevo producto.
  • Actualizar la cantidad de un producto existente (entradas y salidas).
  • Identificar productos por debajo de su nivel mínimo.
  • Guardar todos los cambios en el archivo, de modo que permanezcan disponibles.

Fase 1. Carga o creación del archivo de inventario

El sistema intenta leer el archivo; si no existe, crea uno nuevo con las columnas necesarias. El bloque try / except gestiona ambos casos.

Celda A — carga inicial
import pandas as pd

ARCHIVO = "sistema_inventario.xlsx"

try:
    inventario = pd.read_excel(ARCHIVO)
    print("Inventario cargado desde el archivo.")
except FileNotFoundError:
    inventario = pd.DataFrame(columns=["nombre", "cantidad", "precio", "minimo"])
    print("No se encontró archivo. Se creó un inventario nuevo.")

print(inventario)

Fase 2. Funciones para mostrar y registrar productos

Se definen funciones independientes para cada operación. Reciben el inventario, lo modifican y lo devuelven actualizado.

Celda B — mostrar y registrar
def mostrar_inventario(inv):
    if len(inv) == 0:
        print("El inventario está vacío.")
    else:
        print(inv)

def registrar_producto(inv):
    nombre = input("Nombre del producto: ")
    cantidad = int(input("Cantidad inicial: "))
    precio = float(input("Precio unitario: "))
    minimo = int(input("Nivel mínimo: "))

    nuevo = {"nombre": nombre, "cantidad": cantidad,
             "precio": precio, "minimo": minimo}

    inv.loc[len(inv)] = nuevo   # agrega una fila al final
    print("Producto registrado correctamente.")
    return inv

Fase 3. Actualización de existencias

Esta función localiza un producto por su nombre y suma o resta unidades, según se trate de una entrada o una salida de almacén.

Celda C — actualizar existencias
def actualizar_existencias(inv):
    nombre = input("Producto a actualizar: ")

    if nombre in inv["nombre"].values:
        movimiento = int(input("Unidades (+ entrada / - salida): "))
        # localiza la fila del producto y modifica su cantidad
        fila = inv["nombre"] == nombre
        inv.loc[fila, "cantidad"] = inv.loc[fila, "cantidad"] + movimiento
        print("Existencias actualizadas.")
    else:
        print("El producto no existe en el inventario.")

    return inv

Fase 4. Alertas de reabastecimiento y guardado

Una función revisa qué productos están por debajo del mínimo; otra guarda el inventario en el archivo, garantizando que los datos sean actualizables.

Celda D — alertas y guardado
def revisar_minimos(inv):
    bajos = inv[inv["cantidad"] < inv["minimo"]]
    if len(bajos) == 0:
        print("Todos los productos tienen existencias suficientes.")
    else:
        print("Productos que requieren reabastecimiento:")
        print(bajos[["nombre", "cantidad", "minimo"]])

def guardar(inv):
    # Se calcula la columna "valor" antes de guardar
    inv["valor"] = inv["cantidad"] * inv["precio"]
    inv.to_excel(ARCHIVO, index=False)
    print("Cambios guardados en", ARCHIVO)

Fase 5. Menú principal que integra el sistema

Un ciclo while presenta un menú y ejecuta la función correspondiente según la opción elegida. Este bloque conecta todas las funciones anteriores en un programa único y operativo.

Celda E — menú principal
while True:
    print("\n===== SISTEMA DE GESTIÓN DE INVENTARIOS =====")
    print("1. Mostrar inventario")
    print("2. Registrar producto")
    print("3. Actualizar existencias")
    print("4. Revisar niveles mínimos")
    print("5. Guardar y salir")

    opcion = input("Seleccione una opción: ")

    if opcion == "1":
        mostrar_inventario(inventario)
    elif opcion == "2":
        inventario = registrar_producto(inventario)
    elif opcion == "3":
        inventario = actualizar_existencias(inventario)
    elif opcion == "4":
        revisar_minimos(inventario)
    elif opcion == "5":
        guardar(inventario)
        print("Sistema finalizado.")
        break
    else:
        print("Opción no válida. Intente de nuevo.")
