Diagnóstico de Conocimiento Previo

Reflexione y responda la siguiente cuestión antes de iniciar la revisión teórica. Esta actividad le permitirá autoevaluar su preparación conceptual respecto a la manipulación de datos en planillas electrónicas.

Pregunta de Reflexión Inicial:

"En una planta manufacturera, cinco operadores ingresan manualmente datos de producción en la misma hoja de cálculo. Constantemente se presentan errores tipográficos, fechas desalineadas y sobreescritura accidental de fórmulas. ¿Por qué la simple protección de celdas no resuelve el problema de usabilidad y de qué manera una interfaz orientada a eventos (UserForm) transforma este proceso?"

Análisis Técnico:

La protección de celdas es una medida pasiva que restringe la edición pero no guía el flujo de datos. Un UserForm (Formulario de Usuario) actúa como una capa de abstracción entre el operador y la base de datos de Excel. Permite estandarizar el ingreso mediante controles validados (Listas desplegables, cajas de texto restringidas a números, botones de acción) impidiendo que el usuario final interactúe directamente con la estructura tabular de la hoja.

Marco Teórico y Práctico

Fundamentos de Visual Basic para Aplicaciones (VBA) y UserForms

1. Componentes del Entorno VBE (Visual Basic Editor)

Para acceder al entorno de desarrollo en Excel, se utiliza la combinación de teclas ALT + F11. Un UserForm es un objeto contenedor dentro de VBE donde se diseña la interfaz gráfica de usuario (GUI).

2. Controles Primarios y sus Propiedades

  • Label (Etiqueta): Muestra texto no editable por el usuario. Propiedad clave: Caption.
  • TextBox (Caja de Texto): Permite la entrada de valores alfanuméricos. Propiedad clave: Text o Value.
  • ComboBox (Cuadro Combinado): Lista desplegable para selección estandarizada. Métodos clave: AddItem, Clear.
  • CommandButton (Botón de Comando): Ejecuta rutinas al ser presionado. Evento clave: Click().

3. Programación Orientada a Eventos

A diferencia de la programación secuencial tradicional, el código en UserForms responde a acciones iniciadas por el usuario (hacer clic, cambiar el foco de un campo, cargar el formulario).

' Ejemplo de evento al inicializar el formulario

Private Sub

UserForm_Initialize()

cboCategoria.AddItem "Materia Prima"

cboCategoria.AddItem "Producto Terminado"

End Sub

4. Reglas de Validación Industrial

Toda entrada debe ser verificada antes de escribirse en la base de datos. Se deben evaluar tres aspectos: campos vacíos, tipo de dato correcto (numérico/texto) y coherencia lógica (cantidades mayores a cero).

' =================================================================
' UNIVERSIDAD UNE - PLANTEL CENTRO | COMPUTACIÓN II
' MODULO: frmInventario - CONTROL INTEGRAL DE INVENTARIO
' =================================================================

Private Sub UserForm_Initialize()
    ' Carga inicial de listas desplegables al abrir la interfaz
    With Me.cboCategoria
        .Clear
        .AddItem "Materia Prima"
        .AddItem "Componentes"
        .AddItem "Empaque"
        .AddItem "Producto Terminado"
    End With
    
    With Me.cboTipoMovimiento
        .Clear
        .AddItem "Alta Nuevo Producto"
        .AddItem "Entrada de Stock"
        .AddItem "Salida de Stock"
    End With
End Sub

Private Sub btnRegistrar_Click()
    Dim wsProd As Worksheet, wsEnt As Worksheet, wsSal As Worksheet
    Dim ultimaFila As Long, i As Long
    Dim encon As Boolean
    Dim cant As Double
    
    ' Asignacion de objetos de hoja
    Set wsProd = ThisWorkbook.Sheets("Productos")
    Set wsEnt = ThisWorkbook.Sheets("Entradas")
    Set wsSal = ThisWorkbook.Sheets("Salidas")
    
    ' 1. Validacion de Campos Vacios
    If Trim(Me.txtID.Text) = "" Or Me.cboTipoMovimiento.ListIndex = -1 Then
        MsgBox "Por favor complete el ID del Producto y seleccione el Tipo de Movimiento.", vbExclamation, "Error de Validación"
        Exit Sub
    End If
    
    ' 2. Procesamiento segun Tipo de Movimiento
    Select Case Me.cboTipoMovimiento.Text
        
        Case "Alta Nuevo Producto"
            ultimaFila = wsProd.Cells(wsProd.Rows.Count, 1).End(xlUp).Row + 1
            wsProd.Cells(ultimaFila, 1).Value = Me.txtID.Text
            wsProd.Cells(ultimaFila, 2).Value = Me.txtNombre.Text
            wsProd.Cells(ultimaFila, 3).Value = Me.cboCategoria.Text
            wsProd.Cells(ultimaFila, 4).Value = 0 ' Stock Inicial en Cero
            MsgBox "Producto registrado satisfactoriamente en el catálogo.", vbInformation, "Éxito"
            
        Case "Entrada de Stock"
            If Not IsNumeric(Me.txtCantidad.Text) Then
                MsgBox "Ingrese una cantidad numérica válida.", vbCritical: Exit Sub
            End If
            cant = CDbl(Me.txtCantidad.Text)
            
            ' Buscar producto para actualizar stock
            encon = False
            ultimaFila = wsProd.Cells(wsProd.Rows.Count, 1).End(xlUp).Row
            For i = 2 To ultimaFila
                If CStr(wsProd.Cells(i, 1).Value) = Trim(Me.txtID.Text) Then
                    wsProd.Cells(i, 4).Value = wsProd.Cells(i, 4).Value + cant
                    encon = True
                    Exit For
                End If
            Next i
            
            If encon Then
                ' Registrar historial de entrada
                ultimaFila = wsEnt.Cells(wsEnt.Rows.Count, 1).End(xlUp).Row + 1
                wsEnt.Cells(ultimaFila, 1).Value = Now
                wsEnt.Cells(ultimaFila, 2).Value = Me.txtID.Text
                wsEnt.Cells(ultimaFila, 3).Value = cant
                wsEnt.Cells(ultimaFila, 4).Value = "Entrada por Formulario"
                MsgBox "Entrada de stock registrada correctamente.", vbInformation
            Else
                MsgBox "El ID de producto no existe en el catálogo.", vbCritical
            End If
            
        Case "Salida de Stock"
            If Not IsNumeric(Me.txtCantidad.Text) Then
                MsgBox "Ingrese una cantidad numérica válida.", vbCritical: Exit Sub
            End If
            cant = CDbl(Me.txtCantidad.Text)
            
            encon = False
            ultimaFila = wsProd.Cells(wsProd.Rows.Count, 1).End(xlUp).Row
            For i = 2 To ultimaFila
                If CStr(wsProd.Cells(i, 1).Value) = Trim(Me.txtID.Text) Then
                    ' Validacion de Stock Suficiente
                    If wsProd.Cells(i, 4).Value < cant Then
                        MsgBox "Stock insuficiente. Disponible: " & wsProd.Cells(i, 4).Value, vbCritical
                        Exit Sub
                    End If
                    
                    wsProd.Cells(i, 4).Value = wsProd.Cells(i, 4).Value - cant
                    encon = True
                    Exit For
                End If
            Next i
            
            If encon Then
                ' Registrar historial de salida
                ultimaFila = wsSal.Cells(wsSal.Rows.Count, 1).End(xlUp).Row + 1
                wsSal.Cells(ultimaFila, 1).Value = Now
                wsSal.Cells(ultimaFila, 2).Value = Me.txtID.Text
                wsSal.Cells(ultimaFila, 3).Value = cant
                wsSal.Cells(ultimaFila, 4).Value = "Despacho a Produccion"
                MsgBox "Salida procesada con éxito.", vbInformation
            Else
                MsgBox "El ID de producto no existe.", vbCritical
            End If
            
    End Select
    
    ' Limpiar cajas de texto
    Me.txtID.Text = ""
    Me.txtNombre.Text = ""
    Me.txtCantidad.Text = ""
End Sub

Reflexión y Plan de Transferencia Profesional

La automatización mediante Visual Basic para Aplicaciones y UserForms en Microsoft Excel constituye una competencia transversal crítica para el Ingeniero Industrial contemporáneo. La capacidad de transformar hojas de trabajo pasivas en herramientas dinámicas de gestión reduce drásticamente los tiempos de ciclo en la captura de información, minimiza la tasa de error operativo y establece estándares de calidad acordes con normativas internacionales.

  • Mejora Continua: Evolucionar la lógica de UserForms conectando Excel con bases de datos relacionales externas (como SQL Server o Access) mediante conexiones ADODB.
